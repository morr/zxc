# Bevy 0.19 API cheat sheet

Distilled from `https://bevy.org/learn/migration-guides/0-18-to-0-19/` plus the
event rework carried over from 0.17/0.18. Scoped to what a 2D gameplay project
touches — deep render-pipeline changes are omitted; fetch the guide if you go there.

Verify anything doubtful against
`~/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/bevy-0.19.0/examples/`.

## Events, messages, observers

```rust
#[derive(Event)]        struct NewDayEvent;                       // global
#[derive(EntityEvent)]  struct RestCompleteEvent { entity: Entity }  // entity-targeted
#[derive(Message)]      struct DealDamage { amount: u32 }         // buffered

commands.trigger(NewDayEvent);
app.add_observer(on_new_day);
fn on_new_day(ev: On<NewDayEvent>) {}

app.add_message::<DealDamage>();
fn write(mut w: MessageWriter<DealDamage>) { w.write(DealDamage { amount: 10 }); }
fn read(mut r: MessageReader<DealDamage>) { for m in r.read() {} }
```

- Gone: `EventWriter`, `EventReader`, `add_event::<T>()`, `.send(..)`, `Trigger<T>`,
  `On::target()`, `trigger.event()`.
- `On<E>` derefs to `E`. Destructure it: `let FooEvent { entity } = *event;`
- Lifecycle: `On<Add, C>`, `On<Insert, C>`, `On<Replace, C>`, `On<Remove, C>`, `On<Despawn, C>`.
- Entity-scoped: `commands.entity(id).observe(handler)` — `EntityEvent` only.
- Propagation: `#[entity_event(propagate)]` (+ `auto_propagate` to default it on);
  `ev.propagate(false)` stops it.
- `EntityEvent`'s mutable target methods moved to the `SetEntityEventTarget` trait (0.18).
- Observers accept run conditions (new in 0.19).
- Observers fire once per event — no `for ... in reader.read()` loop.

## ECS core

- **Resources are components.** `#[derive(Resource)]` implies `Component`;
  never `#[derive(Component, Resource)]` on one type. Split it.
- Broad queries now conflict with resource params:
  `Query<EntityMut>` + `Res<T>` → add `Without<IsResource>`.
- `Query::single()` / `single_mut()` return `Result`; `get_single*` removed.
- `MapEntities` is derived by default for resources — drop the manual derive.
- Non-send: `init_non_send_resource` → `init_non_send`, `World::non_send_resource`
  → `World::non_send`, `..._mut` likewise.
- `World::clear_entities()` now also clears resources; `World::clear_all()` clears
  entities + resources + non-send data.
- `World::entities_allocator()` → `World::entity_allocator()`.
- `World::remove_resource_by_id()` returns `bool`.
- Access API dropped the component/resource split: `add_component_read` → `add_read`,
  `has_component_read` → `has_read`, `read_all_components` → `read_all`,
  `is_components_compatible` → `is_compatible` (old names deprecated).
- `EntityComponentsTrigger` gained `old_archetype` / `new_archetype` — pattern
  matches need a `..` arm.
- `System::type_id()` → `System::system_type()`.
- `SystemParam` validation now happens at data-fetch time, not init.
- `SystemBuffer` implementors must provide `queue()`.

## Schedules & systems

```rust
use bevy::ecs::schedule::MultiThreadedExecutor;
schedule.set_executor(MultiThreadedExecutor::new());   // was set_executor_kind(ExecutorKind::..)
```
- `DespawnOnEnter` / `DespawnOnExit` can now fire on same-state transitions.
- `InputDispatchPlugin` and `UiWidgetsPlugins` ship inside `DefaultPlugins` —
  remove manual additions.
- Window exit systems moved to `Last`, grouped under the `ExitSystems` set.
- Render graph is now ECS schedules (`Core2d` / `Core3d`); render passes are systems.

## Text

```rust
TextFont {
    font: handle.into(),          // FontSource: Handle or Family
    font_size: FontSize::Px(16.), // was f32
    ..default()
}
```
- `TextLayout::new_with_justify/linebreak/no_wrap` → `justify` / `linebreak` / `no_wrap`.
- `TextRoot` + `TextSpanAccess` + `TextSpanComponent` collapsed into `TextSection`;
  `read_span()` → `get_text()`, `write_span()` → `get_text_mut()`.
- `PositionedGlyph::span_index` → `section_index`; `byte_index` / `byte_length` removed.
- `Font::try_from_bytes` → `Font::from_bytes` (no `Result`).
- Backend moved Cosmic Text → Parley; layout/measure APIs shifted accordingly.
- `ComputedTextBlock::needs_rerender()` takes `is_viewport_size_changed` and
  `is_rem_size_changed`.
- New in 0.19: `EditableText` (text input), variable fonts, viewport-relative sizes.

## UI

- `ComputedNode::stack_index` → separate `ComputedStackIndex` component.
- `Node` gained `direction: InlineDirection` (defaults `Ltr`).
- Widget de-prefixing: `CoreScrollbarThumb` → `ScrollbarThumb`,
  `CoreScrollbarDragState` → `ScrollbarDragState`, `CoreSliderDragState` → `SliderDragState`.
- `InputFocus.0` is private — use `get()` / `set(entity)` / `clear()`.
- `ViewportNode::camera` is now `Option<Entity>`.
- `UiDebugOptions` gained `outline_border_box`, `outline_padding_box`,
  `outline_content_box`, `outline_scrollbars`, `ignore_border_radius`.
- `Measure::measure`: `width`/`height` → `known_width`/`known_height`; style comes
  from `measure_args.style`.
- Stabilized: `experimental_ui_widgets` → `bevy_ui_widgets`,
  `experimental_bevy_feathers` → `bevy_feathers`; `FeathersPlugin` → `FeathersCorePlugin`.

## Assets & scenes

- Scenes renamed wholesale: `Scene` → `WorldAsset`, `SceneRoot` → `WorldAssetRoot`,
  `DynamicScene` → `DynamicWorld`, `DynamicSceneBuilder` → `DynamicWorldBuilder`,
  `SceneSpawner` → `WorldInstanceSpawner`, `ScenePlugin` → `WorldSerializationPlugin`,
  crate `bevy_scene` → `bevy_world_serialization`, path `bevy::scene::*` →
  `bevy::world_serialization::*`.
- `DynamicWorldBuilder::from_world(world, &registry)` now needs the type registry.
- `Assets::get_mut()` returns `AssetMut<A>`; `AssetEvent::Modified` fires only on
  real mutation.
- `AssetPath::resolve` takes `&AssetPath` (`resolve_str` for `&str`); same for
  `resolve_embed` / `resolve_embed_str`. `get_full_extension()` → `Option<&str>`.
- `Image::pixel_bytes` returns `Result<_, TextureAccessError>`.
- `Reader::seekable()` must be implemented; `AsyncSeekForward` deleted.
- 0.19 headline: **BSN** (`bsn!` macro) for scene definition — new, not required here.

## APIs pre-0.19 priors don't know (verified in release-0.19.0 source)

- `bevy::tasks::futures::check_ready(&mut task)` — poll a `Task<T>` cheaply.
  The old idiom `block_on(future::poll_once(task))` is explicitly warned against
  in `examples/async_tasks/async_compute.rs` (expensive, can block main thread).
- `Camera::viewport_to_world_2d(cam_tf, cursor) -> Result<Vec2, _>` — 2D
  cursor→world directly; no `viewport_to_world(..).origin.truncate()` ray dance.
- `bevy::camera_controller` crate — first-party `PanCamera`/`PanCameraPlugin`
  (keyboard/mouse pan, wheel zoom, `min_zoom`/`max_zoom`) and a free camera.
  Caveats vs `bevy_pancam`: single pan button, no egui-awareness.
- Sprite picking is built-in: `Pickable` on the sprite + `Pointer<Over/Out/Click>`
  entity observers; `SpritePickingPlugin` ships in `DefaultPlugins`. `Mesh2d`
  entities need `MeshPickingPlugin` (NOT in defaults).
- `Res<HoverMap>` (`bevy::picking::hover`) — which entities each pointer is over;
  the standard guard against clicks falling through `bevy_ui` panels (the `ui`
  cargo feature already implies `picking`).
- `smooth_nudge(&target, decay_rate, dt)` from `StableInterpolate` —
  framerate-independent easing/camera-follow; replaces `lerp(t * k)` hacks.
- `commands.delayed().secs(2.).entity(e).insert(..)` — time-delayed commands
  (`examples/ecs/delayed_commands.rs`).
- `ImageLoaderSettings::array_layout = Some(ImageArrayLayout::RowCount { rows })`
  — load one stacked PNG as a layered array texture (feeds `TilemapChunk`).
- Fixed-timestep movement pattern: sim position advanced in `FixedUpdate`,
  visual `Transform` lerped by `Time<Fixed>::overstep_fraction()` in
  `RunFixedMainLoopSystems::AfterFixedMainLoop`, input accumulated in
  `BeforeFixedMainLoop` (`examples/movement/physics_in_fixed_timestep.rs`).
- `bevy::input::common_conditions::input_just_pressed(KeyCode::Escape)` and
  friends; `bevy::time::common_conditions::on_timer` / `on_real_timer`;
  `any_with_component`, `resource_exists`, …
- One-shot logging: `info_once!` / `warn_once!` / `debug_once!` (per call site),
  `once!({ .. })` for arbitrary blocks in hot systems.
- Fallible systems/observers: return `Result<(), BevyError>`, use `?` on
  `query.get(..)`; `app.set_error_handler(bevy::ecs::error::warn)` logs system
  name + error instead of panicking.
- Diagnostics API: `app.register_diagnostic(Diagnostic::new(PATH))`,
  `Diagnostics::add_measurement` in systems, read via `Res<DiagnosticsStore>`.
  Free plugins: `FrameTimeDiagnosticsPlugin`, `EntityCountDiagnosticsPlugin`,
  `SystemInformationDiagnosticsPlugin`, `LogDiagnosticsPlugin` (log spam —
  conflicts with the live-app trace-grep workflow).
- `bevy::settings::SettingsPlugin` + `#[derive(SettingsGroup)]` — auto-persisted
  *user* settings (window, volume, keybinds). Not a replacement for game-design
  RON config.
- `bevy_dev_tools::schedule_data::plugin::SerializeSchedulesPlugin` — dumps all
  schedules/systems/orderings to RON; add temporarily when debugging ordering.
- Sub-states: `#[derive(SubStates)] #[source(AppState = AppState::Playing)]` —
  child state exists only while the source matches.

## Reflection

- `DynamicStruct::index_of()` → `Struct::index_of_name()`.
- `FieldIter` yields `(&str, &dyn PartialReflect)` instead of `&dyn PartialReflect`.
- `bevy_reflect` split into `array`, `enums`, `list`, `map`, `set`, `structs`,
  `tuple`, `tuple_struct` modules.
- `Interned<T>` requires `T: Internable`.

## Errors

- `DefaultErrorHandler` → `FallbackErrorHandler`, `default_error_handler()` →
  `fallback_error_handler()` (deprecated aliases exist).

## Features & deps

- `audio` is no longer implied by `2d`/`3d`/`ui`; default features are
  `2d`, `3d`, `ui`, `audio`.
- `bevy_window` moved to `common_api`; `bevy_input_focus` to `ui_api`;
  `custom_cursor` to `default_platform`. `bevy_picking` no longer implies
  `bevy_input_focus` — `ui_picking` covers focus picking.
- `bevy_log` feature removed; use `trace`. Parallel transform propagation needs
  `multi_threaded`.
- New crate `bevy_material`; `bevy_gltf` optional; `UvChannel` moved to `bevy_mesh`.
- `rand`: `RngCore` → `Rng`, `Rng` → `RngExt`.
- Android minimum API level 26.
